# 🚀 ESP32 LED Blink and Traffic Light Control

This repository contains beginner-friendly ESP32 projects demonstrating basic GPIO programming using **Embedded C**, **Arduino IDE**, and **Wokwi Simulator**.

The projects included are:
- 💡 LED Blinking
- 🚦 Traffic Light Control

These projects were developed as part of my hands-on learning in Embedded Systems and microcontroller programming.

## 💡 Project 1: LED Blinking

### Description
A basic ESP32 program that blinks an LED at regular intervals.

### Features
- GPIO Output Configuration
- LED ON/OFF Control
- Delay Function
- Embedded C Programming

---

## 🚦 Project 2: Traffic Light Control

### Description
A simple traffic light system using three LEDs connected to the ESP32.

### Features
- Sequential LED Control
- Red → Yellow → Green Sequence
- GPIO Programming
- Timing Control using `delay()`
